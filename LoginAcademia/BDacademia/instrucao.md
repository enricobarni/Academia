\# Instruções — Configuração do Banco de Dados (SQL Server Express)



Este projeto utiliza:



\* SQL Server Express

\* SQL Server Management Studio (SSMS)



O banco de dados NÃO utiliza mais:



\* LocalDB

\* arquivos `.mdf` no projeto

\* AttachDbFilename



\---



\# PASSO A PASSO



\## 1. Instalar programas necessários



Instalar:



***\* SQL Server Express***

***\* SQL Server Management Studio (SSMS)***



\---



\## 2. Abrir o SSMS



Conectar em:



***.\\SQLEXPRESS ou NOME-SEU-PC\\SQLEXPRESS***



\---



\## 3. Executar o script SQL



Abrir o arquivo:



***BD\_Academia.sql***



Depois clicar em:



***Execute***



ou pressionar:



***F5***



\---



\## 4. Confirmar criação do banco



No SSMS deve aparecer:



***Databases***

***└── AcademiaBD***



\---



\## 5. ***Rodar o projeto normalmente no Visual Studio***
